If we check the web history through MemProcFS, we can see that the user did follow the link to limewire.

cat forensic/web/web.txt | grep epxlorer.exe

Output:

ID PID Timestamp (UTC) Browser Activity URL Page title
c 7984 2025-07-22 18:52:03 EDGE VISIT https://limewire.com/d/Za2X3#vmzvnIVA3y Download epxlorer.exe | LimeWire
d 7984 2025-07-22 18:51:57 EDGE VISIT https://limewire.com/d/Za2X3#vmzvnIVA3y Download epxlorer.exe | LimeWire
e 7984 2025-07-22 18:51:57 EDGE VISIT https://limewire.com/d/Za2X3#vmzvnIVA3y Download epxlorer.exe | LimeWire
f 7984 2025-07-22 18:51:57 EDGE VISIT https://limewire.com/d/Za2X3?lmwr-ftv=1#vmzvnIVA3y Download epxlorer.exe | LimeWire

You might notice there are only VISIT entries and no DOWNLOAD. LimeWire decrypts files in the browser and saves them from a blob: URL, and MemProcFS can only rebuild the parts of the browser's History database that were in memory, so the download record is most likely missing for one of these reasons. Instead we can confirm the download from the file system:

cat forensic/ntfs/ntfs_files.txt | grep epxlorer

Output:
363f a659a800 1b3a2 1b153 2025-07-22 18:52:06 UTC 2025-07-22 18:53:10 UTC 10f600 A \1\Users\award\Downloads\epxlorer.exe
3640 a659a800 1b3a2 1b153 2025-07-22 18:52:06 UTC 2025-07-22 18:53:10 UTC 7 ARS \1\Users\award\Downloads\epxlorer.exe:SmartScreen 
cat forensic/ntfs/1/Users/award/Downloads/epxlorer.exe_SmartScreen

Anaheim

  • The file is in \Users\award\Downloads\ and was created at 18:52:06, three seconds after the last visit to the LimeWire page.

  • Its size is 0x10f600 = 1,111,552 bytes, exactly what the phishing email told the user to check.

  • It has a 7-byte :SmartScreen alternate data stream (MemProcFS shows it as epxlorer.exe_SmartScreen). It contains Anaheim, Edge's internal codename. Edge writes this after checking a download with SmartScreen, so it tells us the file came through Edge.
